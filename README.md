# hypernumbernet.github.io

GitHub Pages で公開している個人ホームページです。

- サイト: https://hypernumbernet.github.io/
- リポジトリ: https://github.com/hypernumbernet/hypernumbernet.github.io

## 公開設定

このリポジトリ名（`<username>.github.io`）はユーザーサイト用です。
通常は `main` ブランチのルートが公開元になります。

公開されない場合は:

1. リポジトリの **Settings → Pages**
2. Source を **Deploy from a branch**
3. Branch を `main` / folder を `/ (root)`
4. Save
